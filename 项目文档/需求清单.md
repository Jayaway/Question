## 六、关键技术决策

| 决策点 | 选择 | 理由 |
|--------|------|------|
| ORM | MyBatis-Plus 3.5.7 | 文档指定；CRUD 一行代码；分页插件开箱即用 |
| 数据库 | MySQL 8.0 + utf8mb4 | 课程标配；支持 emoji |
| 库名 | `survey_system` | 跟业务名解耦，OQ 重命名不动数据 |
| 自动建库 | `createDatabaseIfNotExist=true` | 老师零配置启动 |
| 自动建表 | `schema.sql` + `IF NOT EXISTS` | Spring Boot 启动即用 |
| 重复启动 | `spring.sql.init.continue-on-error=true` | 第二次启动不报错 |
| JWT | jjwt 0.12.6 + HS256 | 课程级够用，生产改 RS256 |
| API 文档 | Knife4j 4.5.0 jakarta | 启动后 `/doc.html` |
| 包名 | `com.example.survey` | OQ 只是显示名，包名没改 |
| 字段命名 | 驼峰 + `map-underscore-to-camel-case` | 自动映射下划线字段 |

## 七、几个易踩的坑

1. **包名是 `com.example.survey` 不是 `com.example.oq`**（虽然 commit 把项目名改成了 OQ）
2. **`javax.*` 已废弃**，用 `jakarta.*`（Spring Boot 3+/4）
3. **Mapper 扫描二选一**：每个加 `@Mapper` 注解，或在 `QqApplication.java` 加 `@MapperScan("com.example.survey.mapper")`
4. **`mybatis-plus.configuration.log-impl=StdOutImpl`** 会让控制台打每条 SQL，开发好用，生产去掉
5. **Spring Security 默认拦截所有请求**，必须写 SecurityConfig 放行 `/doc.html`
