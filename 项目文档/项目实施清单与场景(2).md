### 二、数据库设计阶段（第 2~3 天）

#### 2.1 数据库操作

- [ ] 终端登录 MySQL：`mysql -u root -p`
- [ ] 创建数据库：`CREATE DATABASE survey_system CHARACTER SET utf8mb4;`
- [ ] 建表（按以下顺序，因为外键依赖）
  1. `sys_user` — 先建，其他表依赖它
  2. `survey` — 依赖 sys_user
  3. `question` — 依赖 survey
  4. `response` — 依赖 survey
  5. `answer` — 依赖 response + question

#### 2.2 建表 SQL（直接复制执行）

```sql
-- 用户表
CREATE TABLE sys_user (
    id BIGINT AUTO_INCREMENT PRIMARY KEY,
    username VARCHAR(50) NOT NULL UNIQUE,
    password VARCHAR(255) NOT NULL,
    email VARCHAR(100),
    create_time DATETIME DEFAULT CURRENT_TIMESTAMP,
    INDEX idx_username (username)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;

-- 问卷表
CREATE TABLE survey (
    id BIGINT AUTO_INCREMENT PRIMARY KEY,
    title VARCHAR(200) NOT NULL,
    description TEXT,
    status TINYINT DEFAULT 0 COMMENT '0-草稿 1-已发布 2-已停止',
    creator_id BIGINT NOT NULL,
    create_time DATETIME DEFAULT CURRENT_TIMESTAMP,
    update_time DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    FOREIGN KEY (creator_id) REFERENCES sys_user(id),
    INDEX idx_creator (creator_id),
    INDEX idx_status (status)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;

-- 题目表
CREATE TABLE question (
    id BIGINT AUTO_INCREMENT PRIMARY KEY,
    survey_id BIGINT NOT NULL,
    type TINYINT NOT NULL COMMENT '1-单选 2-多选 3-文本',
    title VARCHAR(500) NOT NULL,
    options TEXT COMMENT '选项，JSON数组格式 ["A","B","C"]',
    sort_order INT DEFAULT 0,
    required TINYINT DEFAULT 1,
    FOREIGN KEY (survey_id) REFERENCES survey(id) ON DELETE CASCADE,
    INDEX idx_survey (survey_id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;

-- 答卷表
CREATE TABLE response (
    id BIGINT AUTO_INCREMENT PRIMARY KEY,
    survey_id BIGINT NOT NULL,
    respondent_ip VARCHAR(50),
    submit_time DATETIME DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (survey_id) REFERENCES survey(id) ON DELETE CASCADE,
    INDEX idx_response_survey (survey_id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;

-- 答案表
CREATE TABLE answer (
    id BIGINT AUTO_INCREMENT PRIMARY KEY,
    response_id BIGINT NOT NULL,
    question_id BIGINT NOT NULL,
    content TEXT NOT NULL,
    FOREIGN KEY (response_id) REFERENCES response(id) ON DELETE CASCADE,
    FOREIGN KEY (question_id) REFERENCES question(id),
    INDEX idx_answer_response (response_id),
    INDEX idx_answer_question (question_id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;
```

#### ⭐ 2.4 提交项目时数据库怎么处理（必看）

> ##### JwtAuthFilter.java — JWT 过滤器

```java
@Component
public class JwtAuthFilter extends OncePerRequestFilter {

    private final JwtUtil jwtUtil;

    @Override
    protected void doFilterInternal(HttpServletRequest request,
                                    HttpServletResponse response,
                                    FilterChain filterChain)
            throws ServletException, IOException {
        // 1. 从请求头取 token：Authorization: Bearer xxxxxx
        String token = extractToken(request);

        // 2. 如果 token 有效，解析 userId 放入 SecurityContext
        if (token != null && jwtUtil.validateToken(token)) {
            Long userId = jwtUtil.getUserIdFromToken(token);
            UsernamePasswordAuthenticationToken auth =
                    new UsernamePasswordAuthenticationToken(userId, null, List.of());
            SecurityContextHolder.getContext().setAuthentication(auth);
        }

        // 3. 继续执行后续过滤器
        filterChain.doFilter(request, response);
    }
}
```

> ##### JwtUtil.java — 生成和验证 JWT

```java
@Component
public class JwtUtil {
    private final SecretKey key;
    private final long expiration;

    // 从 application.yml 读取 jwt.secret 和 jwt.expiration
    public JwtUtil(@Value("${jwt.secret}") String secret,
                   @Value("${jwt.expiration}") long expiration) {
        this.key = Keys.hmacShaKeyFor(secret.getBytes(StandardCharsets.UTF_8));
        this.expiration = expiration;
    }

    public String generateToken(Long userId) {
        return Jwts.builder()
                .subject(String.valueOf(userId))
                .issuedAt(new Date())
                .expiration(new Date(System.currentTimeMillis() + expiration))
                .signWith(key)
                .compact();
    }

    public Long getUserIdFromToken(String token) {
        return Long.parseLong(Jwts.parser()
                .verifyWith(key).build()
                .parseSignedClaims(token).getPayload()
                .getSubject());
    }

    public boolean validateToken(String token) {
        try {
            Jwts.parser().verifyWith(key).build().parseSignedClaims(token);
            return true;
        } catch (JwtException e) {
            return false;
        }
    }
}
```

```java
@RestController
@RequestMapping("/api/auth")
public class AuthController {
```

> ##### SurveyController.java — 问卷 CRUD 接口

核心写法：从 `Authentication auth` 拿当前用户 ID

```java
@RestController
@RequestMapping("/api/survey")
public class SurveyController {

    @PostMapping
    public Result<?> create(@Valid @RequestBody SurveyDto dto, Authentication auth) {
        Long userId = (Long) auth.getPrincipal();   // ← 从 JWT 解析出的用户ID
        Survey s = new Survey();
        s.setTitle(dto.getTitle());
        s.setDescription(dto.getDescription());
        Survey created = surveyService.create(s, userId);
        return Result.success(Map.of("id", created.getId()));
    }

    @GetMapping
    public Result<?> list(@RequestParam(defaultValue = "1") int page,
                          @RequestParam(defaultValue = "10") int size,
                          @RequestParam(required = false) String keyword,
                          Authentication auth) {
        Long userId = (Long) auth.getPrincipal();
        IPage<Survey> result = surveyService.list(userId, page, size, keyword);
        return Result.success(Map.of("records", result.getRecords(),
                "total", result.getTotal(), "pages", result.getPages()));
    }

    @GetMapping("/{id}")
    public Result<?> detail(@PathVariable Long id) {
        Survey survey = surveyService.getById(id);
        List<Question> questions = questionService.getBySurveyId(id);
        return Result.success(Map.of("survey", survey, "questions", questions));
    }

    @PutMapping("/{id}")
    public Result<?> update(@PathVariable Long id, @Valid @RequestBody SurveyDto dto) {
        Survey s = new Survey();
        s.setId(id); s.setTitle(dto.getTitle()); s.setDescription(dto.getDescription());
        surveyService.update(s);
        return Result.success();
    }

    @DeleteMapping("/{id}")
    public Result<?> delete(@PathVariable Long id) {
        surveyService.delete(id);
        return Result.success();
    }

    @PutMapping("/{id}/status")
    public Result<?> updateStatus(@PathVariable Long id, @RequestBody Map<String, Integer> body) {
        surveyService.updateStatus(id, body.get("status"));
        return Result.success();
    }
}
```

> ##### ResponseServiceImpl.java — 提交答卷 + 统计（重点！）

**submit() — 使用 @Transactional 保证数据一致性**：

```java
@Transactional   // ← 关键注解！整个方法在一个数据库事务中执行
public void submit(Long surveyId, Map<Long, String> answers, String ip) {
    // 1. 校验问卷存在且已发布
    Survey survey = surveyMapper.selectById(surveyId);
    if (survey == null || survey.getStatus() != 1) throw ...

    // 2. 创建答卷记录
    Response response = new Response();
    response.setSurveyId(surveyId);
    response.setRespondentIp(ip);
    responseMapper.insert(response);

    // 3. 逐条插入答案（如果中间失败，①②③全部回滚）
    for (Map.Entry<Long, String> entry : answers.entrySet()) {
        Answer answer = new Answer();
        answer.setResponseId(response.getId());
        answer.setQuestionId(entry.getKey());
        answer.setContent(entry.getValue());
        answerMapper.insert(answer);
    }
}
```
