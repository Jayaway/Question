## 一、项目题目

**在线问卷调查与数据分析系统**

亮点：既有 CRUD 基础功能，又有 ECharts 数据可视化展示，答辩时图表效果好，老师提问空间大（图表怎么渲染的？数据怎么聚合的？），好发挥。

## 二、技术栈

| 层面 | 技术 | 理由 |
|------|------|------|
| 框架 | Spring Boot 2.7+ / 3.x | 课程要求 |
| ORM | MyBatis-Plus | 比 JPA 更灵活，CRUD 一行代码，分页插件开箱即用 |
| 数据库 | MySQL 8.0 | 标配 |
| 认证 | Spring Security + JWT | 老师必问，体现安全意识 |
| 缓存 | Redis（可选，用于热点数据缓存） | 加分项 |
| API 文档 | Knife4j（Swagger 增强版） | 自动生成接口文档，答辩展示很专业 |
| 前端 | Vue 3 + Element Plus | 上手快，组件丰富 |
| 可视化 | ECharts | 问卷统计图表 |
| 项目管理 | Git + Gitee/GitHub | 提交记录也是成绩的一部分 |

## 六、答辩常见提问（提前准备）

1. **"JWT 和 Session 的区别？为什么选 JWT？"**
   → 无状态、跨域友好、适合前后端分离架构

2. **"MyBatis-Plus 和 JPA 的区别？"**
   → MP 更灵活、学习成本低、分页插件好用、条件构造器强大

3. **"Spring Security 的过滤器链是怎么工作的？"**
   → 画图说明 Filter Chain 流程，UsernamePasswordAuthenticationFilter → JWT Filter → 认证成功/失败处理器

4. **"如何处理跨域问题？"**
   → `@CrossOrigin` 注解 / 全局 CorsFilter 配置

5. **"你的数据库表怎么设计的？有哪些索引？"**
   → 提前画好 ER 图，能说出每张表的主键、外键、索引

6. **"XX 功能你是怎么实现的？"**
   → 把代码逻辑讲清楚：Controller 接收请求 → Service 处理业务 → Mapper 操作数据库

7. **"为什么要用 ECharts？数据怎么传给前端的？"**
   → 后端做 SQL 聚合（COUNT + GROUP BY），返回 JSON 数据，前端 ECharts 绑定数据渲染

8. **"事务在哪个地方用了？为什么？"**
   → 答卷提交：同时插入答卷记录和多条答案，需要保证原子性，用 `@Transactional`

## 九、提交项目时数据库怎么处理

有三种方案，**建议方案一 + 方案二一起用**：

### 方案一（推荐）：Spring Boot 自动建表

在 `src/main/resources/` 下放 `schema.sql` 和 `data.sql`，`application.yml` 配置：

```yaml
spring:
  datasource:
    url: jdbc:mysql://localhost:3306/survey_system?createDatabaseIfNotExist=true&useSSL=false
    username: root
    password: 123456
  sql:
    init:
      mode: always
      continue-on-error: true
```

老师只需确保 MySQL 运行中，启动项目即可，无需手动建库建表。

### 方案二（保底）：`sql/init.sql`

项目根目录保留完整建库 SQL 文件，老师也可以用命令行手动导入。

### 方案三（加分项）：H2 内存库 + MySQL 双模式

通过 Spring Profile 切换，默认用 H2 零安装启动，切 `--spring.profiles.active=mysql` 用 MySQL。
